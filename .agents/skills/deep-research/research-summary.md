## Key Findings

1. **Multi-angle research**: Steelman, skeptic, primary data, recent developments — four essential passes
2. **Surface disagreement**: When sources conflict, say so directly — don't smooth over
3. **Never fabricate**: A flagged gap is more useful than a confident guess
4. **Source triangulation**: Cross-reference across 3+ independent sources using different methodologies
5. **Lateral reading**: Don't evaluate a source by its own claims — leave the page and verify
6. **Scale to stakes**: Simple facts don't need this skill; contested claims do

## Mode System Recommendation

**Pattern: Depth Modes (Lite/Standard/Deep/Ultra)**

More granular than typical intensity because research has distinct depth levels.

## Key Scans

1. **Source check**: All claims attributed to named sources?
2. **Triangulation check**: Key claims supported by 3+ independent sources?
3. **Bias check**: Confirmation bias avoided? Disconfirming evidence searched for?
4. **Gap analysis**: What wasn't found and should have been?
