# Deep Research — Source Evaluation

## The SIFT Method

| Step | Action |
|------|--------|
| **S**top | Don't read or share immediately. Check your emotional response. |
| **I**nvestigate source | Use lateral reading — leave the page, search for what others say about the source. |
| **F**ind better coverage | Look for multiple trusted sources reporting the same thing. |
| **T**race claims back | Find the original data, video, or study. Ensure context wasn't stripped. |

## Source Credibility Tiers

| Tier | Definition | Examples |
|------|-----------|----------|
| **Primary** | Original data, direct from source | Peer-reviewed study, official filing, API documentation, firsthand account |
| **Authoritative secondary** | Expert analysis of primary sources | Meta-analysis, reputable journalism, technical book from recognized expert |
| **Community** | Discussion, reviews, crowd-sourced | Forum posts, Reddit, review sites — note as anecdotal |
| **Unverifiable** | Can't confirm original source | Anonymous claims, unlinked statistics, "studies show" without citation |
| **Discredited** | Known to be false or unreliable | Debunked studies, fabricated data, known misinformation sources |

## Bias Detection

| Bias Type | Signal | Mitigation |
|-----------|--------|------------|
| **Confirmation** | Only citing sources that agree with the desired conclusion | Search for "criticism of X" or "problems with X" |
| **Source** | Source has clear financial/institutional stake in the claim | Check funding, ownership, and conflicts of interest |
| **Recency** | Treating newest information as most accurate | Check if new findings contradict or refine existing consensus |
| **Selection** | Cherry-picking data points that support a narrative | Look for the full dataset, not just cited excerpts |

## Triangulation Rule

For any high-confidence claim:
- Verify across at least 3 independent sources
- Sources must use different methodologies or perspectives
- If they disagree, surface the disagreement — don't pick the one that "sounds right"
