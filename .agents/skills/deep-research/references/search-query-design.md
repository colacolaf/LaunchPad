# Deep Research — Query Design

## Angle-Specific Query Templates

### Steelman / Proponent

| Query Pattern | Example |
|--------------|---------|
| "Why [topic] works" | "Why intermittent fasting works" |
| "Benefits of [topic]" | "Benefits of remote work productivity" |
| "[Topic] success stories" | "Startup bootstrapping success stories" |
| "How to succeed at [topic]" | "How to succeed at learning a new language" |

### Skeptic / Critic

| Query Pattern | Example |
|--------------|---------|
| "Why [topic] fails" | "Why intermittent fasting fails" |
| "Problems with [topic]" | "Problems with remote work" |
| "[Topic] criticism" | "Bootstrapping criticism limitations" |
| "[Topic] failure rate" | "Language learning failure rate" |

### Primary Data

| Query Pattern | Example |
|--------------|---------|
| "[Topic] study [year]" | "Remote work productivity study 2024" |
| "[Topic] statistics data" | "Startup funding statistics" |
| "site:gov [topic]" | "site:gov remote work guidelines" |
| "site:edu [topic]" | "site:edu language acquisition" |

### Recent Developments

| Query Pattern | Example |
|--------------|---------|
| "[Topic] [current year]" | "Remote work trends 2026" |
| "[Topic] update latest" | "Intermittent fasting latest research" |
| "[Topic] new [year]" | "Startup funding new 2026" |
| "[Topic] latest changes" | "Language learning latest research" |

## Query Design Principles

- **Be specific, not broad**: "Bootstrapped SaaS MRR benchmarks" > "Startup revenue"
- **Use exact phrases**: "site:reddit.com 'first month'" for real-world experiences
- **Search for disagreement**: If initial results all agree, search for dissent specifically
- **Don't prime for confirmation**: Alternate between supporting and opposing queries
