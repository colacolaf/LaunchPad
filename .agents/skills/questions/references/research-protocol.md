# /questions — Research Protocol

## When to Research

- **Lite**: Only when a factual claim needs verification. One search per claim.
- **Full**: Every major claim gets checked. Each angle gets a supporting search AND a counter-search.
- **Ultra**: Every claim from every angle gets exhaustive multi-source research. Both supporting and opposing evidence.

## Search Strategy

### For Each Angle, Search Both Sides

| Angle | Supporting Search | Counter Search |
|-------|------------------|----------------|
| Market | "Why [type] businesses succeed" | "Why [type] businesses fail" |
| Competition | "Best [product/service]" | "Worst [product/service] complaints" |
| Tech feasibility | "How to build [X]" | "Problems with [X] common pitfalls" |
| Economics | "Pricing for [X]" | "Hidden costs of [X]" |

### Source Quality Hierarchy

1. **Primary sources**: Original data, official docs, first-hand accounts
2. **Authoritative secondary**: Peer-reviewed, expert analysis, reputable journalism
3. **Community**: Forums, review sites, discussion boards (note as anecdotal)
4. **Inferred**: Reasoned from first principles (label clearly)

### Documentation

For each research finding, record:
- **Source**: URL or citation
- **Claim**: What was found
- **Confidence**: High/Medium/Low (based on source quality)
- **Relevance**: Which angle it informs

## What to Do When Research Is Thin

1. Say so explicitly — don't pad with weak sources
2. Lower the confidence score in the verdict
3. Note "this claim could not be independently verified" rather than guessing
4. Flag as "Needs More Research"

## Never Do

- Invent a stat to sound rigorous
- Treat a single source as definitive
- Present researched claims and inferred claims with the same confidence
- Skip research because "I already know this"
